## 复现与试用

```sh
npm run build
npm test
bash scripts/smoke-headless.sh
bash scripts/smoke-headless.sh npm run test:calendar
```

有桌面环境时可直接运行 `npm run test:smoke` 和 `npm run test:calendar`。两套界面测试均使用临时数据库。

打开客户端的「计划」，点击「月历」。重点试用：安排与截止分开显示、拖动安排卡片后截止不变、带提醒的截止改期、单次重复改期、撤销，以及列表/月历切换后数量一致。
